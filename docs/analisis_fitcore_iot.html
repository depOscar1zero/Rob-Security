1 — Descripción general del proyecto

FitCore IoT Security es un sistema de detección de intrusos en tiempo real compuesto por hardware físico (NodeMCU ESP8266 + sensor PIR HC-SR501 + buzzer), un backend en Firebase Realtime Database y una app Android en React Native / Expo. Adicionalmente incluye tres dispositivos simulados en HTML/JS: smartwatch, Smart TV y asistente de voz via IFTTT.

3 — Schema Firebase RTDB

Schema objetivo (PIR v1.1) — ya documentado en firebase_schema.json

/sensor/movimiento    ← bool  (true cuando el PIR detecta movimiento)
/sensor/estado        ← string ("calentando" | "desarmado" | "armado" | "alerta" | "alarma")
/sensor/alerta        ← bool
/sensor/timestamp     ← number
/config/armado        ← bool  (la app escribe aquí para armar/desarmar)
/alertas/{pushId}     ← { tipo: string, timestamp: number }
✅ firebase_schema.json actualizado correctamente El archivo docs/firebase_schema.json ya refleja el schema PIR v1.1. No contiene distancia_cm del sensor HC-SR04 descartado. Los nodos /sensor, /config/armado y /alertas están documentados correctamente.
