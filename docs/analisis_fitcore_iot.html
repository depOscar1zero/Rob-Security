1 — Descripción general del proyecto

FitCore IoT Security es un sistema de detección de intrusos en tiempo real compuesto por hardware físico (NodeMCU ESP8266 + sensor PIR HC-SR501 + buzzer), un backend en Firebase Realtime Database y una app Android en React Native / Expo. Adicionalmente incluye tres dispositivos simulados en HTML/JS: smartwatch, Smart TV y asistente de voz via IFTTT.

2 — Estado del código

Firmware activo: CodigoArduino/

Este es el firmware validado por M1. Ya funciona y escribe valores en Firebase RTDB. Estructura de archivos:

  • CodigoPrincipal.ino — Lógica principal: lectura PIR cada 1200 ms, buzzer, escritura a Firebase
  • ConexionFirebase.h — Configuración WiFi + Firebase (credenciales en local, no subidas al repo)
  • Buzzer.h — Funciones de inicialización, activación y apagado del buzzer
✅ Lo que funciona correctamente Lectura del PIR cada 1200 ms · Activación del buzzer al detectar movimiento · Escritura booleana a Firebase RTDB · Warmup de 30 s para estabilización del PIR · Reconexión WiFi implícita por la librería Firebase_ESP_Client

🔴 Bloqueo crítico para M3 El firmware escribe en /garage/motion pero M3 va a leer /sensor/movimiento. Mientras no se alinee este path, M3 no puede avanzar en su tarea de S2. Es un cambio de una sola línea en el firmware.

Firmware secundario: firmware/fitcore_security/

Este es un firmware alternativo que usa sensor ultrasónico HC-SR04 (descartado) + ArduinoJson + REST HTTP. Tiene implementada la máquina de estados completa (DISARMED → ARMED → ALERT → ALARM) y puede servir como referencia directa para M1 al implementar la máquina de estados en S3, adaptando la lógica del sensor ultrasónico a un simple digitalRead().

3 — Schema Firebase RTDB

Schema objetivo (PIR v1.1)

/sensor/movimiento    ← bool  (true cuando el PIR detecta movimiento)
/sensor/estado        ← string ("calentando" | "desarmado" | "armado" | "alerta" | "alarma")
/sensor/alerta        ← bool
/config/armado        ← bool  (la app escribe aquí para armar/desarmar)
/alertas/{pushId}     ← { tipo: string, timestamp: number }
⚠ firebase_schema.json desactualizado El archivo docs/firebase_schema.json todavía tiene el campo distancia_cm del sensor HC-SR04 descartado. M2 debe actualizarlo para que refleje el schema PIR real antes de que M3 empiece a conectar la app.
