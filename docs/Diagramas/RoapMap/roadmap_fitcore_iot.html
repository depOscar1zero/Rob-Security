S3 Máquina de estados y lógica de alarma PIR v1.1 ▶
M1 — Hardware
M1
Validar máquina de estados completa en hardware real: WARMUP (30 s) → ARMED → ALERT → ALARM → despejado → ARMED. Probar cada transición.El HC-SR501 mantiene HIGH ~2 s después del último movimiento. Esto es normal, no es un bug.
M1
Firmware lee /config/armado de Firebase cada 2 s para obedecer armar/desarmar remoto desde la app.
M2 — Backend
M2
Cada evento se registra en /alertas/{pushId} con tipo ("alerta" | "alarma" | "despejado") y timestamp.El firmware hace POST a /alertas.json que genera automáticamente el pushId único de Firebase.
M3 — App
M3
Indicador visual de estado: círculo grande con colores. Verde = armado, amarillo = alerta, rojo = alarma, gris = desarmado.
